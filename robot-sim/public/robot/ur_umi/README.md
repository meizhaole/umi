# UR5 + UMI Gripper URDF

`ur5_umi.urdf` combines the original UR5 description with the fixed-root UMI gripper subtree. The `ur5_to_umi_mount` transform is marked DEBUG / PLACEHOLDER and uses identity; it is not a measured installation transform. UMI mesh URIs resolve through `umi_gripper` to `/robot/umi-gripper/`.
